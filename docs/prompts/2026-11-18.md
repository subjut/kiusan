1. "Read AGENTS.md. Make a proposal for a versioning system. It would be nice, if the version number only has to be updated in one place and propagates everywhere. The version should also appear in the footer. Ask questions using the ask_user tool."

   Proposed a versioning scheme: a root `VERSION` file (the single bump
   point) embedded via `go:embed` into a `Version` var (new `version.go`,
   the `data/timezones.txt` pattern), propagated to the footer of every
   page via a `pageData.Version` field filled in `renderPage`; semver
   starting at `0.5.0` (user's choice). Design questions asked via
   ask_user (source of truth, scheme, scope); the user chose the VERSION
   file + 0.5.0 and challenged the `X-Kiusan-Version` header — answered
   that for a no-API site the footer alone serves the admin use case, the
   header stays an optional one-liner; no /version endpoint or JS global
   (no consumers). Proposal delivered, implementation pending approval.
