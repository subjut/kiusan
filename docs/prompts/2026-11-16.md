   field-length caps, 50-year end dates, deterministic marks) built `test.db`
   and printed the admin links; verified by booting the server on it (all
   pages 200, full matrices + totals rows); `test.db` gitignored, AGENTS.md
   documents the tool + the `KIUSAN_DSN=./test.db` plug-in (chosen, no server
   code change); edge-case suggestions listed.

2. "What does the DSN in KIUSAN_DSN stand for?"

   Answered: DSN = Data Source Name, the connection string handed to the GORM
   dialector (a file path for sqlite, `user:pass@tcp(...)` for mysql, a
   `postgres://` URI for postgres).
