# Prompt log

Verbatim log of the prompts given to the agent in this repository, grouped
per session day. The prompts are the project's steering history: they
survive agent-session compaction and can be handed to a fresh agent
verbatim.

Conventions:

- Prompts are quoted exactly as given, typos and all.
- A short note follows each prompt: what it produced or decided.
- Entries marked *(wording lost)* belonged to a compacted conversation
  whose summary preserved only the substance.
- Transcript markers like "function call failed" in Zed's thread history
  are failed agent tool calls (e.g. truncated write batches), not user
  prompts, and are not logged here.
- Entries are appended automatically with every prompt — verbatim plus
  a one-line outcome note, written before the session summary (rule in
  `AGENTS.md` → Conventions).

26. "It's still not right. The table still scrolls. Additionally, there is now a white box on the right side of the table, if the table is shorter than the container div."
    → Removed `width: 100%` from `.table-scroll`: a percentage width
      resolves against the container in the parent's intrinsic
      sizing pass, so `.table-breakout`'s `max-content` collapsed to
      the container width — the breakout then sized to the container
      (hence scroll on wide tables and a white surplus of box when
      the table was short). With `width: auto` the scroll box's
      content max-content (the table's) feeds the breakout's
      `min(max-content, …)` sizing again: hugging when short, breaking
      out centered when wide, scrolling only past the viewport cap.
      Full `-race` suite green.

27. "Not fixed. Still exactly the same symptoms as in my last prompt."
    → The pure-CSS `max-content` sizing never resolved to the table's
      width (all three attempts degraded to the container width —
      white box on short tables, scrollbar on wide ones). New
      approach: `poll.js` measures the table's rendered width and sets

      degrades to the container width. Could not verify in a browser
      (headless Firefox hangs in the sandbox); full `-race` suite and
      `node --check` green.
