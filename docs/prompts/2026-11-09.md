Another addition: Turn the instruction text green, when the user answered all options. Turn it back yellow, when the user deselects an option when he previously had selected all options."

   instruction now carries an `ok` state (green, `--mark-green-text`) toggled
   in `vote.js` `refreshSubmit` — green while complete, amber again on
   deselection. `node --check` + `go test ./...` green.
