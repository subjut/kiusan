2. "Bug: The submit answer button does not shake and does not turn red when the disabled submit button is pressed (observed in Firefox and Edge; even after server restart).
Another addition: Turn the instruction text green, when the user answered all options. Turn it back yellow, when the user deselects an option when he previously had selected all options."

   Root cause: browsers fire no click events at all for disabled controls
   (neither on them nor passed to ancestors), so the rect hit-test never
   triggered — `style.css` now adds `pointer-events: none` to
   `button:submit:disabled`, so the click targets the `.form-actions` container
   behind the button and the existing form-level hit-test catches it; the
   instruction now carries an `ok` state (green, `--mark-green-text`) toggled
   in `vote.js` `refreshSubmit` — green while complete, amber again on
   deselection. `node --check` + `go test ./...` green.
