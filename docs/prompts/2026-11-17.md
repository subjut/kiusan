3. "I have another option: drop the "Browser default" from the UI entirely, like option A, but don't set a language cookie, unless the user explicitly selects another language.    select, per user decision — raw navigator matching stays out of JS) and

   with no shipped catalog stays implicit in the English fallback (no cookie,
   per user decision). Implemented: the `value=""` row is gone, the select
   carries `data-implicit` (i18n.go's new `implicitLang`: Accept-Language →
   shipped → English), `renderPage` marks the resolved language selected
   (`localeChosen` deleted), `locale.js` re-syncs the selection on load and
   pins/un-pins the `kiusan-locale` cookie against `data-implicit` (the
   `""`-fetch special case is gone); `nav.browserDefault` dropped from both
   catalogs. Verified: go build/vet/test (new dropdown selected-state +
   data-implicit assertions in i18n_test.go), node --check, jstest 41/41
   (new effective-language-sync + pin/un-pin tests, the browser-default test
   rewritten); AGENTS.md updated (both Commands test bullets, the render.go /
